A tiny program that writes one weekly status-report line to a text file. The line is a
single sentence of at most 200 characters: an AI agent's funniest one-line summary of
its week to its human.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
